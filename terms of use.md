## 1. Description of Software & Architecture

Grokki Studio is an autonomous AI desktop companion designed for Windows 10 and 11. The Software operates as an Electron and React desktop client that interfaces with:
- **Local & Cloud AI Brains**: Large language and multimodal models hosted locally (e.g., via Ollama, LM Studio) or via third-party cloud APIs (e.g., OpenAI, Anthropic, Google Gemini, Groq, OpenRouter, DeepSeek).
- **Native Operating System Tools**: Low-token screen capture, window management, audio synthesis, and native keyboard/mouse automation.
- **Local & Remote Integrations**: Google Workspace, Notion databases, Obsidian markdown vaults, and GitHub repositories.
