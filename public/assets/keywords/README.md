# Custom Wake Word Keyword Models (.ppn)

To use a custom wake word (like "Hey Grokki"):
1. Go to https://console.picovoice.ai/
2. In the Porcupine Wake Word section, type "Hey Grokki" and select "Windows".
3. Download the generated `.ppn` file and place it into this `assets/keywords/` folder.
4. Grokki will automatically detect and load your custom `.ppn` model!

Otherwise, Grokki supports built-in offline keywords:
- JARVIS (Default)
- COMPUTER
- HEY_SIRI
- HEY_GOOGLE
- ALEXA
- TERMINATOR
